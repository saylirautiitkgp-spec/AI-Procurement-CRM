MOTHERSON LOGO
==============
The platform shows a plain "MOTHERSON" wordmark placeholder until you add the official logo.

Put the official file here, named exactly one of:
    motherson-logo.svg   (preferred)
    motherson-logo.png
    motherson-logo.webp
    motherson-logo.jpg

Reload the page: the server detects the file and the header uses it automatically. The logo sits on a white plate,
so a dark logo stays readable in both the light and the dark theme. No code change is needed.
